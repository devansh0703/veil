States, as the merchant actually sees them

loading
Skeleton bars in place of each figure, with reconciling · 6 RPC calls beside them. The layout does not move when the numbers land.
empty
“No private payments yet.” Plus one action that copies the alias and one link to the three-line integration. Never just “No data”.
rpc error
“Can’t reach devnet. Showing the last-known ledger from 13:04 UTC.” Never blank, never silent zeros, and the timestamp is never rounded away.
partial
Ciphertext in the amount cell, an unreadable · key v1≠v2 pill, and the row still counted settled. Hiding it would break the total; faking it would break the point.
refused
A row that has a refusal code instead of an amount: VEIL-CONF-005, VEIL-CONF-004, VEIL-CONF-003. It keeps the code and never gains an amount it did not settle, which is why the ledger can be trusted to add up.
export
Enabled the moment the ledger has rows; disabled, with the reason in its tooltip, when it does not. The download writes exactly the rows on screen and respects the current view — in public view the amount column exports as redacted, never the ciphertext it is hiding. On failure it says why and produces no file: a partial CSV is worse than no CSV.
